# Arc Layout

**Date:** 2026-10-27
**Agent:** Claude Opus 5.5
**Branch:** `arc-layout`, PR to `main`
**Status:** ✅ Complete; section 2 of ARC-PARITY.md ticked

## User Intention
Replicate Arc's layout while keeping Cove's top-tab mode (ARC-PARITY.md,
section 2): navigation in the sidebar header beside the traffic lights, a URL
pill showing only the domain, no toolbar above the page in sidebar mode,
Arc's sections (Favorites, Pinned, Clear, Today), a footer, a resizable
sidebar, an 8pt page inset, chromeless hidden modes, and hidden top tabs that
float over the page instead of pushing it down. Layout only; colors, shadows
and motion are for the look-and-feel agent.

## What We Accomplished

### Shell
- ✅ **Page card inset 8pt.** The gutter token split: `gutter` (6) stays for
  the titlebar band, `cardInset` (8) is the gap around the card and the
  sidebar's horizontal inset. The card's concentric corners come out at ~8.
- ✅ **No toolbar in sidebar mode.** `NavigationBar` collapses to zero height
  rather than leaving the tree, so the mode switch still animates. Back,
  forward and reload moved into `NavigationControls`, shared by the bar and
  the sidebar header.
- ✅ **Hidden top tabs float.** The tab row has a docked position that
  collapses to the card inset and a floating twin flush with the window's top
  (so only its bottom corners show), mirroring the sidebar's docked/floating
  pair. `chromeFloatingSurface` is shared by both floating pieces.
- ✅ **Resizable sidebar.** A handle over the sidebar-to-card gap drags the
  width, 220–400pt, persisted as `browser.sidebarWidth`. The lower bound is
  what fits traffic lights + four header controls.

### Sidebar (`SidebarTabView`)
- ✅ **Header:** `●●● ◧ ← → ↻`. Leading inset is computed from the traffic
  light inset for both the docked and the floating sidebar.
- ✅ **URL pill** (`SidebarAddressPill`): lock/globe/search glyph and the
  domain. Clicking calls `session.requestAddressFocus()`, the one entry
  point; the field then edits the full URL in place. Return and Escape hand
  focus back to the window and the pill reverts to the domain. ⌘L with the
  sidebar hidden reveals it, and the auto-hide waits while editing.
- ✅ **Sections:** Favorites grid and Pinned rows render only with content,
  fed by empty `TabManager.favorites` / `pinned`. A continuous Clear line
  shows "Clear" on hover; `clearTodayTabs()` closes Today and leaves a fresh
  tab. Today has the New Tab row on top and lists `tabs.reversed()`.
- ✅ **New tabs open at the end of the strip**, which is the top of Today.
  Tabs from links still open next to their opener.
- ✅ **Footer:** downloads (leading, popover opens upward) and a single space
  dot (center). No new-space button until Spaces exist.

### Address field focus (`AddressTextField`)
Three fields now live in the tree at once (bar, docked pill, floating pill):
- `focusRequest` is `Int?`; `nil` means "not the live one". Only the address
  UI of the current mode gets the real value, so one ⌘L can't focus two
  fields, and a request made while a field was dormant is dropped rather than
  replayed when it becomes live.
- `acceptsFirstResponder` is false except during a click on the field or an
  explicit `focus()`. Otherwise AppKit hands the window's initial focus to the
  first text field it finds (previously the navigation bar, which is why the
  start page's own search field never got focus; now it does).
- Focus is reported from `becomeFirstResponder`, not
  `controlTextDidBeginEditing`, which only fires on the first keystroke.

## Key Learnings
- **Test harness** (session scratchpad): launch the worktree build with
  `open -n … --args -browser.showTabsInSidebar YES …`, find the window with
  `CGWindowListCopyWindowInfo` by owner PID, `screencapture -l`. Keyboard
  events posted with `CGEvent.postToPid` reach the instance regardless of
  focus, but menu shortcuts and button clicks need the window to be key, and
  SwiftUI hover only follows the real cursor, so clicks and moves go through
  the HID tap after `NSRunningApplication.activate`.
- **Other agents' instances steal activation** while they test. Several
  sequences had to be re-run; verify the window is key in every capture
  (colored traffic lights) before trusting it.
- `ConcentricRectangle` flush with the window's top gives the window's own
  radius at the top corners and the minimum at the bottom, which is exactly
  what a floating band needs; no second shape.
- The scratchpad is shared with sibling agents; keep tools in a subfolder.

## Deferred
- The sidebar header and pill overlay the scroll view (macOS extends it under
  the titlebar); with many tabs, rows scroll under the pill. A `safeAreaBar`
  with a soft scroll edge effect might be nicer but risks drawing outside the
  floating sidebar's corners; left for look-and-feel.
- The pill has no hover fill (it reads as a field). Easy to add if wanted.
- Drop zones for Favorites/Pinned come with drag to reorder (5a); pinning
  itself with 5d.
