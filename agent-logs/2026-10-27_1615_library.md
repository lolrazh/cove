History, opened from the sidebar footer's leading button, ⌘⇧L and the
Command Bar; download progress on that button; and bookmark import from

## What We Accomplished

### Closed tabs go to the archive
- ✅ `ArchivedTab` has a `reason`, `.idle` (the sweep) or `.closed` (by
  hand), in a new `reason` column; an `ALTER TABLE` adds it to archives
  made before. `closeTab` archives the tab with its `savedTab`, so the
  back/forward list is kept, as in Arc.
- ✅ **Reopen Last Closed Tab** takes `archive.lastClosed`, the newest
  `.closed` entry, so an idle tab archived since doesn't jump the queue,
  and restores it through the restore path, history included. The History
  menu's Recently Closed lists the last ten closed entries.
  `RecentlyClosedTabs` is gone.
- ✅ **Private windows** get a `TabArchive(directory: nil)`: SQLite in
  memory (`Database.inMemory`), gone with the window. Their closed tabs
  reopen and show in their own Library, never in the shared archive, and
  the sweep never archives in them (`archiveAfter` is nil when private).

### The Library (`Cove/Sources/Library/`)
- ✅ **`LibraryModel`**, one per window, owned by `TabManager` like the
  Command Bar: `isPresented`, the section, and the actions (reopen an
  archived tab, open a page, history by day, copy a link). Switching
  layouts closes it rather than carrying it over.
- ✅ **In the sidebar it takes the tabs' place**, pushed in from the
  trailing edge (a crossfade under Reduce Motion), with Back and a title
  on the traffic lights' line. I chose this over a popover: Arc does it,
  the sidebar is already a column of rows the Library's lists fit, and a
  popover above the footer would cover the tabs anyway while being
  narrower. The footer stays, and so does 5h's media card, which sits
  between the Library and the footer: it belongs to the window, not to
  the tabs. A hidden sidebar comes out for the Library and stays out while
  it's open.
- ✅ **With tabs on top it's a popover** (340×460) from the button at the
  end of the navigation bar. That bar stays in the window, collapsed, in
  sidebar mode, so only it presents, and only with tabs on top
  (`showsPopover`).
- ✅ **Sections** under a custom segmented control (the selected tab raised
  like the sidebar's active tab). The system one asked for more width than
  a 220pt sidebar has, and pushed everything off its edges.
  - **Downloads**: the old popover's rows, rebuilt on a shared `LibraryRow`:
    the file icon in a progress ring, size or status, cancel / show in
    Finder / remove, click to open, a context menu, and Clear.
  - **Archive**: search (the Command Bar's `QueryMatch`, now internal),
    favicon, title, address and how long ago; click reopens the tab whole,
    hover shows delete (`TabArchive.remove`).
  - **History**: search over the FTS store, grouped by day (`HistoryDay`,
    moved out of the History window to share), each page once at its
    latest visit, 150 at most; click opens it in a new tab.
- ✅ **The History window stays.** It's the full view: every visit,
  multi-select, delete, copy. The Library is for finding a recent page
  quickly, with a button that opens the window.
- ✅ **⌘⇧L** (Browser › Library) toggles it; the Command Bar's **Library**
  command opens it (keywords downloads, archive, history).

### Downloads in the footer
- ✅ **`LibraryButton`** replaces `DownloadsStatusButton` and
  `DownloadPopover`. While files download its symbol becomes an arrow in
  a progress ring (`overallProgress`); when one finishes it bounces and
  wears an accent dot until the Library shows Downloads
  (`DownloadManager.hasUnseenDownloads`, `markDownloadsSeen`). The symbol
  is one view that swaps glyphs, so the bounce lands on it. Opening the
  Library while a download runs or is unseen goes to Downloads.

### Bookmark import (parsers only)
- ✅ **`ImportedBookmark`**: `.page(title:url:)` or `.folder(title:children:)`.
- ✅ **`BookmarkImport.bookmarks(from:)`** tells the formats apart by
  content (Chrome's file has no extension): Safari's `Bookmarks.plist`
  (Decodable over `PropertyListDecoder`; Favorites and Bookmarks Menu
  under their shown names; History proxies and the Reading List skipped)
  and Chrome's `Bookmarks` JSON (bookmark bar, other, mobile). Only http(s)
  pages, so bookmarklets drop out; empty folders drop out.
- ⏳ The open panel (the sandbox needs user-selected access, already
  entitled) and inserting the tree into Pinned folders wait for 5d's model.

## Key Learnings
- **A system segmented `Picker` won't shrink.** Three equal segments sized
  to the widest overflowed the sidebar and centered the whole column past
  both edges; the row titles looked like they didn't truncate.
- **`symbolEffect(.bounce, value:)` needs a view that persists.** Swapping
  between two images on completion inserts a fresh one that never sees the
  value change; one image with `contentTransition(.symbolEffect(.replace))`
  bounces.
- **A launch while another app holds focus gets no window** until Cove is
  activated (SwiftUI opens the first window on activation here), so the
  harness's screenshot-by-PID finds nothing.
