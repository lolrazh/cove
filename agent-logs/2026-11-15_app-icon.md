# Cove app icon — 15 November 2026

## Request

Use the approved Cove mark as the app icon. Try simple blue-green backgrounds and a handpainted option. Make a native layered icon in Apple Icon Composer, open the build, keep commits small, and push to main.

The user explicitly approved the main display for this work because Virtual 16:9 was off.

## Work

- Redrew the approved raster silhouette as a clean white SVG. The contour remains organic; the vector does not retain the original raster paint texture. Two generated alpha-cutout attempts had stray pixels and were not used.
- Generated a separate blue-green brush texture with the built-in imagegen tool. The exact prompt and provenance are in `design/branding/README.md`.
- Created a native document in the Icon Composer bundled with Xcode. Imported the SVG and configured a separate glass foreground. Used 30% translucency and a 28% neutral shadow.
- Saved three editable background experiments: solid Lagoon, automatic-gradient Tidal, and Painted water. Imported the painted texture in its own group, moved it below the mark, and disabled glass and translucency on the paint.
- Exported all three Default appearance previews from Icon Composer at 1024 points, 1x. Added a local comparison page with full-size, 64px, and 32px samples.
- Selected Tidal as the initial build candidate. This is not a final user choice among the backgrounds.
- Added `Cove/Resources/AppIcon.icon` to `project.yml` and regenerated the Xcode project. The existing AppIcon setting now resolves to this document. No browser behavior changed.

## Checks

- Debug macOS build passed with `CODE_SIGNING_ALLOWED=NO`, using `build/dia-polish` as derived data.
- Build log: `/tmp/cove-app-icon-build.log` (local only).
- Xcode invoked actool for the native `.icon` input and produced `Assets.car` and `AppIcon.icns`.
- Built Info.plist contains `CFBundleIconName = AppIcon` and `CFBundleIconFile = AppIcon`.
- All four native documents have valid local layer references. Production icon JSON matches the Tidal study.
- All three exported PNGs exist and have distinct hashes.
- The first restart from the existing build path still showed a placeholder in About Cove. A copy of the same built bundle at `build/icon-preview/Cove.app` showed the new teal Cove icon. This is consistent with a stale macOS icon cache at the old path; no cache database was deleted and Dock was not restarted.
- Verified the new icon visually in About Cove with computer use. Closed About and left the browser open on the main display.
- Dock accessibility timed out, so the Dock pixels were not independently captured. The app was launched with the new icon, and the About panel confirms that the running bundle resolves it.
- No browser regression suite was run for this asset-only change. The build reported an out-of-date CoreSimulator service and a skipped AppIntents metadata extraction; neither blocked the macOS build.
